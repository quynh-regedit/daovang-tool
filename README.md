# GOM XU ĐÀO VÀNG - AI Prediction Tool

Tool dự đoán BNB cho game Telegram Mini App.

## Deploy lên GitHub Pages (HTTPS miễn phí)

1. Tạo repo mới trên GitHub (public)
2. Upload toàn bộ file trong folder này
3. Vào Settings → Pages → Source: main branch / root
4. URL sẽ là: https://TÊN_BẠN.github.io/TÊN_REPO/
5. Copy URL đó → BotFather → Configure menu button
